# Support

For the fastest useful report, ask OpenClaw:

```text
Use skyrim_diagnostics_report to write a no-change first report. Summarize the top findings and do not apply changes.
```

If a maintainer needs attachments:

```text
Use bug_report_bundle with zip_output=true and redact_user_paths=true. Tell me where the zip was written.
```
