What It Solves

Mods Downloaded But Not Working

Checks whether the active Vortex profile is actually deployed into Skyrim Data, whether plugins are enabled, and whether SKSE should be the launch route.

Huge Collection Confusion

Builds mod knowledge reports, flags known stack mistakes like FNIS plus Pandora, detects missing masters, and explains risky conflicts without deleting anything.

Popups, Crashes, Logs

Reads Papyrus, SKSE, crash, and plugin logs. Runtime watch returns newly appended errors, and the optional popup capture helper can save screenshot/OCR evidence into a case folder.

Vortex Open Workflow

vortex_open_status explains when read-only tools can keep running while Vortex is open, and applied profile writes now return post-apply verification.

OpenClaw Workflow

First

Run validate_setup or skyrim_diagnostics_report. OpenClaw reads the summary and top findings before touching detailed sections.

Vortex

Use Deployment Doctor and Launch Doctor to confirm the active profile, deployed files, plugin state, SKSE route, and audio archives.

MO2

Use MO2 reports for virtual profile state. Launch Skyrim, SKSE, and xEdit from MO2 so the selected profile's files are visible.

Undo

Risky fixes go through profile backups, cloned-profile previews, dry runs, and clear restore plans. The MCP does not blind-delete mods or sort load order.

Local Tool, Public Docs

This Vercel site is documentation and onboarding. The actual MCP must run on the same Windows or WSL2 machine that can see Skyrim, Vortex, MO2, profiles, and logs.

That design is intentional: your mod files, logs, Nexus key, and profile backups stay local unless you choose to share a generated report.

Important: a cloud deployment cannot diagnose your local Skyrim install by itself. Install the repo locally, register the MCP in OpenClaw, then use this site as the friendly reference.
